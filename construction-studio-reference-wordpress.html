Construction Studio: what it calculates

A student's reference to the assemblies, data and arithmetic inside the tool — and an explicit account of what it does not model.

5 element slots 30 systems 19 build-ups 15 materials 27 sizing rules

This is a structural and constructional tool, not a building-physics one

Construction Studio computes no thermal, hygrothermal or carbon quantity of any kind. There is no U-value, no R-value, no thermal mass, no decrement delay, no condensation check and no embodied carbon anywhere in the source. There are no surface resistances, because there is no heat-flow calculation for them to belong to.

This is not a simplified implementation of BS EN ISO 6946 — it is an absent one. No material in the tool carries a thermal conductivity, a density in kg/m³, a specific heat capacity or a vapour resistivity.

Two things in the interface can mislead on this point. A build-up layer labelled Vapour control layer is a name and a thickness (1 mm) used to draw and colour the layer; no vapour resistance is attached to it and nothing reads it. And the material table stores a property called density — but in kN/m³, which is self-weight for load calculation, not the kg/m³ a heat-capacity calculation would need.

1 — What a student can buildFive slots, thirty systems, nineteen fixed build-ups

A building is assembled by choosing one system for each of five slots. The slots are fixed; there is no way to add a sixth.

SlotSystemsExamples
Foundation4pad, strip, raft, piles and caps
Ground floor4ground-bearing slab, beam and block, suspended RC, suspended timber
Wall & Structure9RC frame, RC shear walls, cavity masonry, steel moment / braced / portal frame, timber platform frame, post and beam, CLT
Floor7RC on beams, flat slab, waffle, hollowcore, composite steel, timber joist, CLT
Roof6concrete flat, insulated metal deck, portal rafters, trussed rafter, cut rafter, CLT flat
 There is no opening element. Windows, doors, rooflights and their reveals, lintels and cills are not modelled at all — not as geometry and not as anything else.

Assemblies come from presets only

Each system names one of 19 build-ups: a fixed, ordered list of layers, outermost first. A student cannot add a layer, delete a layer, or reorder the stack. The build-up you get is the one the system carries.

What a student can change about a layer

Only thickness, and only where a system exposes a parameter whose key matches a layer's key. In practice that means:

  • Insulation thickness — on every system that has an insul parameter (ranges from 0–200 mm on cavity masonry to 50–250 mm on ground floors).
  • The structural layer — which normally follows the sizing rule automatically, but is overridden by a thk parameter where one exists (RC wall 180–400 mm, CLT panel, ground slab 100–300 mm).
  • Named build-up dimensions that a system happens to expose: slabDepth, topping, void, cavity, outerT, innerT.

Every other layer thickness is fixed in the source. A student cannot change a layer's material, cannot substitute one product for another, and cannot mark a layer as ventilated or unventilated.

Per-element editing

Clicking a single member opens a sheet where exactly two things can be changed: its section (picked from the section library) and whether it exists (delete). Edits are keyed to the element's position on the grid so they survive the building being regenerated; an edit whose address no longer exists is reported as an orphan rather than silently dropped.

The file format contains an array named manual, described in the source as "elements the student drew: never regenerated" — but nothing in the interface ever writes to it. There is no drawing tool. That array is always empty.

Build-up layers use a different, much thinner vocabulary

The 15 materials above are used for members — beams, columns, slabs. A build-up layer does not reference them. It carries a single family token used to pick a drawing colour, from a set of eight: timber, board, insul, void, metal, concrete, masonry, steel. "Rigid insulation" and "mineral wool between studs" are both simply insul, and the tool knows nothing that distinguishes them.

Where the values come from

The source states three provenances and no others:

  • Steel sections follow EN 10365 (the IPE, HEA and HEB tables are transcribed with h, b, tw, tf, A, Iy, Iz, Wel and It).
  • Span rules are attributed to Allen & Iano, The Architect's Studio Companion, "and the standard steel and concrete references".
  • The masonry slenderness limit is attributed to EN 1996.

The material property values themselves (E, ν, density, characteristic strengths, partial factors) carry no citation in the code. They are consistent with standard Eurocode values, but the source does not say so and a student should not cite the tool as their authority.

Can a student add or edit a material?

No The library is a fixed array evaluated when the page loads. There is no material editor, no import path for materials, and no part of the interface that writes to it. The only material-adjacent choice a student makes is picking a different section for an individual member.

Three kinds of arithmetic run, and the source is explicit that they are preliminary-design rules rather than analysis.

B. Load takedown

Gravity only, by tributary area, with no frame action, no continuity and no moment anywhere. Uniformly distributed loads in kN/m² come from a five-entry table selected by building use:

Useresidentialofficeretailindustrialroof
kN/m²91112145
 Single combined figures — the source does not separate permanent from variable actions, and applies no load factors.

On a column-supported building each grid node takes its tributary area × the load of every level above, accumulated downward. On a wall-supported building the total is divided by the perimeter run to give kN/m. The source asserts two invariants, both tested: the support loads must sum to the floor loads, and each level's member reactions must sum to that level's load.

C. Horizontal load path and eaves thrust

A level's load is shared among the members that span it in proportion to the strip each carries; each member delivers half of what it collects to the support at either end (w·L/2). A member is classified by geometry alone — the unit vertical component of its direction — as vertical (|uy| > 0.94), horizontal (< 0.09) or inclined. An inclined member also pushes its support sideways:

H = V × (run ÷ rise) i.e. H = V / tan(pitch)

the thrust a pitched roof puts into its walls

D. The one code check

Masonry wall slenderness, attributed to EN 1996: hef / tef ≤ 27, reduced to ≤ 20 where the thinnest leaf is under 90 mm in two storeys or more. For a cavity wall tef = ⅔(t₁ + t₂). The source states its own assumption: hef is taken as the clear storey height — a wall held top and bottom and free at the sides — and real restraint factors are not modelled.

Not calculated

absent U-value   absent R-value   absent thermal mass   absent decrement delay   absent condensation risk   absent embodied carbon   absent surface resistances

Surface resistances deserve a specific note because the question is a natural one: there are no Rsi or Rse values in the tool at all, and therefore no question of whether they vary by element type or heat-flow direction. The tool has no concept of inside and outside as thermal environments — only a build-up's from: 'outside' flag, which controls which end of the stack is drawn first.

4 — What is not modelledRead this section before relying on any output

  • All heat transfer. No conduction, convection or radiation is computed. Thermal bridging does not arise as a question — neither repeating (the studs at 400 mm centres in the drawing above are geometry only) nor non-repeating (junctions, and there is no ψ-value anywhere).
  • Air gaps and cavities. Layers named "Drained cavity", "Ventilated cavity", "Clear cavity", "Ventilated void" and "Service void" are thicknesses with a colour. The tool does not distinguish ventilated from unventilated, and assigns no resistance to any of them.
  • All moisture transport. There is no steady-state check to go beyond — no Glaser method, no interstitial condensation assessment, no surface condensation or mould risk, no vapour resistivity data.
  • Structural analysis. The source is explicit: "no frame action, no continuity, no moment anywhere". Nothing checks strength, stability, deflection, buckling, fire or connections. Wind and seismic loads are absent; so are load factors and load combinations.
  • Openings. No windows, doors or rooflights, and therefore no lintels, cills, reveals, or any of the junctions where both heat and structure actually get complicated.
  • Acoustics, daylight, ventilation, cost. None are modelled. Layers named "Acoustic screed", "Resilient layer" and "Resilient bar" are drawn, not evaluated.
  • Ground and site. One number describes the ground: an allowable bearing pressure, default 150 kPa. No soil profile, no water table, no settlement, no slope.

The connections the tool draws between systems are derived and explained — each junction is resolved from the pair of materials meeting there and carries a written rationale — but they are not designed. No fixing, weld, bolt or fastener is sized.

View and study controls

Three levels of detail (diagram / members / full assembly), four display modes (shaded, realistic, wireframe, x-ray), an explode slider, an Open slider that swings the enclosure aside, a section box, per-layer visibility, a build sequence, a two-scheme comparison, and a load-path overlay with arrows. These change what is shown, never what is computed.

6 — How it compares to established toolsWhere the comparison applies, and where there is nothing to compare

Against BS EN ISO 6946, WUFI, or any thermal tool

There is no basis for comparison. A U-value calculated to BS EN ISO 6946 is ΣR including surface resistances, with corrections for fasteners, air gaps and inverted roofs; a WUFI run is transient coupled heat and moisture transport. Construction Studio produces neither a number nor an approximation of one. It would not "diverge" from those methods — it does not attempt them.

The one thing a student can legitimately take from the tool into a thermal calculation is geometry: a build-up's layer sequence and the thicknesses as drawn. Those are a reasonable starting sketch for a hand calculation done elsewhere, provided the student supplies every λ value themselves and treats the insulation-between-studs layer as the repeating thermal bridge it is — something the tool draws but does not flag.

Against structural software

Here there is a meaningful comparison, and the tool is honest about where it sits. A span-to-depth first pass is what a preliminary design actually does, and the depths it produces should land close to a designed member for regular, simply supported, gravity-only cases in the span ranges each rule declares. It will diverge, sometimes badly, wherever the things it omits matter: continuity, cantilevers, point loads, irregular grids, lateral stability, vibration, fire, and any serviceability limit. Its column and footing sizes follow from a single combined kN/m² figure with no load factors, so they are indicative of scale only.

Building Regulations compliance

Not acceptable for any part of any regulatory submission — not Part L, not Part A, not anything else. For Part L and its equivalents the question does not even arise, since no thermal quantity exists. For structure, the tool's own on-screen disclaimer is the correct statement of its status:

"These are rules of thumb for learning and for early design. They are not analysis and not design. Nothing here checks strength, stability, deflection, fire, buckling or connections."

Cite it as a teaching model of construction assembly and load path. Do not cite it as a source of material property data, and do not cite it for building physics at all.

ExercisesThree things this tool can genuinely teach

These teach construction and structural principles. None of them is a building-physics exercise, because the tool cannot support one — a thermal exercise would have to be done on paper using the geometry taken from the screen.

1 · Why a floor system is chosen before a grid is fixed

Span-to-depth · structural zone · storey height

  1. Start from the steel office template. Set bays to 3 × 3 and both spans to 6.0 m.
  2. Record the beam size and the total floor zone from the build-up panel for each of these four floors in turn: composite steel, RC flat slab, precast hollowcore, timber joist.
  3. Now change both spans to 12.0 m and record the same four again.
  4. Multiply each floor zone by 4 storeys and add it to 4 × 2.7 m of clear height to get a building height for each option.

What to look forAt 6 m the four systems are within roughly a hundred millimetres of one another and the choice is about buildability and cost. At 12 m they separate sharply, and one of them (timber joist) has left its declared span range entirely — the panel says so. The difference in total building height across four storeys is the argument a structural engineer makes at the first meeting.

2 · Where a pitched roof actually pushes

Thrust · H = V / tan θ · why a tie exists

  1. Build a two-storey masonry house: cavity masonry wall, trussed rafter roof, spans 7.5 × 6.0 m, use set to residential.
  2. Open the Analysis tab and turn the load path on. Set the filter to inclined and read the thrust figure at the eaves.
  3. Change the roof pitch from 35° to 20°, then to 50°, recording the thrust each time.
  4. Plot thrust against pitch for those three values and compare the shape of your plot with 1/tan θ.

What to look forHalving the pitch roughly doubles the outward push, because the relationship is a cotangent, not a proportion. This is why a shallow pitch needs a substantial tie and why a steep roof was the sensible form before trusses. Note also that the tool gives you the horizontal force but does not check whether the wall can resist it — that judgement is yours.

3 · What a wall has to do besides hold the roof up

Build-up sequence · the structural layer within the assembly

  1. Set Wall & Structure to timber platform frame, detail to Full assembly, and open the build-up drawing.
  2. Write down all nine layers in order, with thicknesses, and against each one state in your own words the single job it does.
  3. Set the insulation to its minimum, 90 mm, then its maximum, 240 mm. Note what happens to the overall wall thickness — and what happens to the studs.
  4. Now switch to cavity masonry and to CLT and identify, in each, which single layer carries the load and where it sits in the stack.

What to look forIn the timber wall the insulation and the structure occupy the same 140 mm — the tool marks it within the studs — so thickening the insulation past the stud depth changes the drawing in a way that ought to make you ask what really happens on site. In the masonry wall the load-bearing leaf is the inner one, which surprises most students. In CLT, one layer does structure, racking and airtightness at once. That comparison is the point; the thermal consequence of each is a calculation you must do elsewhere.
